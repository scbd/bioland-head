# Details: 0007. Per-environment config database topology

## Prerequisite, independent of the ruling

`I18N_DB_CONNECTION_LIMIT` defaults to 5 (`nuxt.config.ts:64-66`,
`server/utils/translate/index.js:38`) and must be raised before the first flip, since config reads
join the translation workload on one pool. A deployment action, not a code change; it gates OPS-1
and survives this ruling unchanged.

## Context

Every connection value is an environment variable resolved at runtime
(`nuxt.config.ts:57-66` → `server/utils/translate/index.js:33-40`). Nothing here records which
server a deployment points at, so the topology is an operator fact. This ADR names the variables
only; no host, credential, or connection string appears in this repo.

Plan decision 6 scopes the registry to one `env` x `multiSiteCode` deployment and calls that the
tightest blast radius. That holds only if the environments do not share a server — a topology we do
not control. So the decision is the mechanism, not the fact.

## Decision

Treat p02-01's `env` column as load-bearing: apply `WHERE env = ?` on every registry read, whatever
the operator eventually answers. On a shared server the predicate is the isolation; on distinct
servers it is a no-op. A missing filter silently serves prod a dev row, so it is tested either way.

## Consequences

- **p02-01 and p02-02 are unblocked now.** The operator's answer becomes an optimisation, not a
  gate, and relaxes testing rather than releasing work.
- p02-01 step 3 already keeps `env` columns "as the only defense if a DB is ever shared", so this
  hardens the drafted shape rather than redesigning it.
- Cost is one predicate and its test.

## Rejected

- **Wait for the operator to confirm distinct servers per environment.** Correct isolation if true,
  but it is the operator's state to report, not ours to choose, and waiting blocks p02-01/p02-02.
- **Distinct servers plus a separate `CONFIG_DB_*` variable set.** Strongest isolation — config
  reads stop sharing the translation pool and its `acquireTimeout: 30000` (C13). Cost: new
  operator-supplied variables and credentials per environment, dropping plan decision 1b's "zero new
  infrastructure" property. No task in this plan writes a `.env*` path (Plan Rule 26).
