# 0012 details — head theme resolution contract

## Numbering

`docs/adr/` did not exist in this repo before this file. The number starts at 0012, not 0001,
because the `config-endpoint` plan holds a binding reservation on head ADRs 0006 through 0011
and treats 0001 through 0005 as already allocated. Nothing was lost in the 0001-0011 range; those
numbers are spoken for and land later.

## Precedence (D2)

`biolandSettings.theme` > site `config.theme` > `runTime.theme` > code defaults. A leg supplies a
leaf when the leaf is present, not when it is truthy, so `maxRowsPerColumn: 0` stays 0 instead of
falling through.

## Merge depth (MD)

Merge one leaf at a time, two levels deep (`theme.<group>.<leaf>`). A site authoring only
`color.primary` still inherits the rest from the network leg. A whole-object merge would blank
every key the site did not restate.

`hero.primary` is derived as `[color.primary, color.secondary]` only when absent from every
source. An authored hero passes through untouched. Verified against the live fleet: 8 records
(4 distinct site codes across 2 networks) carry an authored `hero.primary` whose second slot is
not the derived value, so an always-derive rule would visibly change them. No record on the fleet
lacks an authored hero, so the derive branch never fires in production today. It exists to make
the read total.

`hero` has no authoring surface. It is derived, never authored.

## Fall-through on absence (accepted flicker)

dmsm swallows errors when it attaches `biolandSettings`. A Drupal blip therefore drops the key for
one cache window, and a saved site briefly reverts to fallback branding. This is accepted, not a
defect to design around.

## Columns (W2a)

`theme.home_page_widgets.columns` is a sequence of sequences. The outer length is the grid-column
count and validates to exactly 3, matching the hardcoded `col-md-4` at
`app/components/page/home-chm.vue:18`. A column-count-aware grid is deferred: see `docs/debt.md`.

## Reset (RS)

The module's Theme tab ships "Reset to network default", which deletes the key and falls through
per D2. That work is module-side. The head only has to make absence total.

## Staleness (ST)

The <=5-minute head Nitro TTL is the only staleness, by design. No cache-bust work is planned.

## Evidence

Fleet parity was measured on 2026-08-24 over 444 site records and 4,884 read comparisons, with 0
unexplained deltas: the resolver reproduces every pre-refactor rendered value. The 444 and 4,884
figures count records and comparisons processed, not distinct sites.
